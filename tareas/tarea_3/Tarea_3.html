Ejercicio 3.1: Regresión Logística

Desarrollo Analítico

Definimos la probabilidad de fallecimiento post-cirugía para el \(i\)-ésimo paciente como \(\pi_i = \Pr(Y_i = 1)\). Se proponen las siguientes variables predictoras: - \(x_{i1} = 1\) si el paciente es tratado, \(0\) si es control. - \(x_{i2} = 1\) si el riesgo es medio, \(0\) en otro caso. - \(x_{i3} = 1\) si el riesgo es alto, \(0\) en otro caso.

Y las interacciones: - \(x_{i12} = x_{i1} x_{i2}\) - \(x_{i13} = x_{i1} x_{i3}\)

Dado que el riesgo de cirugía tiene 3 categorías, sus variables indicadoras \(x_{i2}\) y \(x_{i3}\) abarcan todos los niveles respecto al nivel de referencia (riesgo bajo). En total, tenemos \(N=6\) categorías o patrones de covariables (2 niveles de tratamiento \(\times\) 3 niveles de riesgo).

Expresaremos cada hipótesis en términos del predictor lineal y determinaremos los grados de libertad de la estadística de devianza, donde \(df = N - p\), siendo \(p\) el número de parámetros libres en el modelo.

a) \(H_1\): No hay asociación entre tratamiento y respuesta en cualquier categoría de riesgo.

Bajo esta hipótesis, la probabilidad de fallecimiento depende únicamente del riesgo de la cirugía y no del tratamiento recibido. Por tanto, omitimos la variable de tratamiento y sus interacciones. El modelo de regresión logística es:

\[ \text{logit}(\pi_i) = \beta_0 + \beta_2 x_{i2} + \beta_3 x_{i3} \]

Este modelo tiene \(p = 3\) parámetros (\(\beta_0, \beta_2, \beta_3\)). Los grados de libertad de la estadística de devianza son \(df = N - p = 6 - 3 = 3\).

b) \(H_2\): El logaritmo de la razón de momios que asocia tratamiento y respuesta es constante entre las categorías de riesgo.

El logaritmo de la razón de momios (log OR) del tratamiento frente al control se representa como la diferencia de los logits. Si este log OR es constante para cualquier nivel de riesgo, significa que no existen interacciones entre el tratamiento y el riesgo. El modelo es:

\[ \text{logit}(\pi_i) = \beta_0 + \beta_1 x_{i1} + \beta_2 x_{i2} + \beta_3 x_{i3} \]

Este modelo tiene \(p = 4\) parámetros (\(\beta_0, \beta_1, \beta_2, \beta_3\)). Los grados de libertad de la estadística de devianza son \(df = N - p = 6 - 4 = 2\).

c) \(H_3\): El logaritmo de la razón de momios que asocia tratamiento y respuesta se relaciona linealmente con una covariable continua, \(x_{i4}\), que expresa el nivel de riesgo de la cirugía.

Sustituimos los indicadores categóricos de riesgo por una covariable continua \(x_{i4}\). La hipótesis afirma que el log OR del tratamiento cambia linealmente con el nivel de riesgo \(x_{i4}\), lo cual implica un término de interacción entre \(x_{i1}\) y \(x_{i4}\). El modelo se especifica como:

\[ \text{logit}(\pi_i) = \beta_0 + \beta_1 x_{i1} + \beta_4 x_{i4} + \beta_5 (x_{i1} x_{i4}) \]

Este modelo tiene \(p = 4\) parámetros (\(\beta_0, \beta_1, \beta_4, \beta_5\)). Asumiendo que aún tenemos 6 patrones únicos en nuestros datos observados (aunque el riesgo sea continuo, sus valores únicos siguen reflejando las 6 combinaciones), los grados de libertad de la devianza son \(df = 6 - 4 = 2\).

d) \(H_4\): La transformación logit de \(\pi_i\) se relaciona linealmente con \(x_{i4}\), con pendiente común para ambos grupos: tratados y control.

Dado que la pendiente con respecto al nivel de riesgo continuo \(x_{i4}\) es común para ambos grupos, no existe interacción entre el tratamiento y \(x_{i4}\). El modelo es:

\[ \text{logit}(\pi_i) = \beta_0 + \beta_1 x_{i1} + \beta_4 x_{i4} \]

Este modelo cuenta con \(p = 3\) parámetros (\(\beta_0, \beta_1, \beta_4\)). Los grados de libertad de la estadística de devianza son \(df = N - p = 6 - 3 = 3\).

Para calcular los intervalos de confianza para las razones de momios de combinaciones lineales, extraemos los coeficientes y su matriz de varianzas y covarianzas:

# Coeficientes estimados y matriz de covarianzas
beta_hat <- coef(M_main)
Sigma_hat <- vcov(M_main)

# Nivel de confianza del 95%
alpha <- 0.05
z <- qnorm(1 - alpha/2)

1. Intervalo de confianza para \(e^{\beta_1 + \beta_3}\)

La combinación lineal es \(L_1 = \beta_1 + \beta_3\).

# El vector de contrastes para L1 = beta_1 + beta_3
c1 <- c(0, 1, 0, 1, 0, 0, 0)
L1_hat <- sum(c1 * beta_hat)

# Varianza de L1
var_L1 <- t(c1) %*% Sigma_hat %*% c1
se_L1 <- sqrt(as.numeric(var_L1))

# Intervalo de confianza para L1
ci_L1_inf <- L1_hat - z * se_L1
ci_L1_sup <- L1_hat + z * se_L1

Ejercicio 3.3: Análisis de datos binarios

a) Ajuste del modelo de regresión logística

Las variables predictoras se definen como: - \(x_{i1} = 1\) si la cesárea fue planeada, 0 en otro caso. - \(x_{i2} = 1\) si algún factor de riesgo estuvo presente, 0 en otro caso. - \(x_{i3} = 1\) si se administraron antibióticos como medida preventiva, 0 en otro caso.

Construimos el data.frame equivalente a la Tabla 2:

df_ej3_3 <- data.frame(
  cesarea_planeada = c(1, 1, 1, 1, 0, 0, 0, 0),
  riesgo = c(1, 0, 1, 0, 1, 0, 1, 0),
  antibioticos = c(1, 1, 0, 0, 1, 1, 0, 0),

# Ajuste del modelo logístico de efectos principales
M_inf <- glm(cbind(infeccion, sin_infeccion) ~ cesarea_planeada + riesgo + antibioticos,

b) Intervalo de confianza al 95% para la probabilidad de infección

Condiciones: cesárea no planeada (\(x_{i1}=0\)), sin factores de riesgo (\(x_{i2}=0\)) y sin antibióticos (\(x_{i3}=0\)).

Dado que todas las variables son \(0\), la transformación logit de la probabilidad de infección equivale al intercepto estimado (\(\hat{\beta}_0\)).

# Creamos el data.frame con las nuevas observaciones
nuevo_dato_b <- data.frame(
  cesarea_planeada = 0,
  riesgo = 0,
  antibioticos = 0
)

# Hacemos la predicción sobre el predictor lineal
pred_b <- predict(M_inf, newdata = nuevo_dato_b, type = "link", se.fit = TRUE)

# Obtenemos los límites en la escala del predictor lineal
lim_inf_b_link <- pred_b$fit - z * pred_b$se.fit
lim_sup_b_link <- pred_b$fit + z * pred_b$se.fit

# Usamos la inversa del logit (plogis) para regresar a probabilidades
pi_b_inf <- plogis(lim_inf_b_link)
pi_b_sup <- plogis(lim_sup_b_link)
pi_b_est <- plogis(pred_b$fit)

cat("Probabilidad estimada:", pi_b_est, "\n")

A pesar de la amplitud, que se debe a que la información para esa subpoblación base es escasa, el estimado puntual es del \(37.2\%\).

c) Razón de momios e intervalo de confianza al 95% para un cambio en el riesgo

Mujer 1: se administran antibióticos, tiene factores de riesgo y cesárea no planeada. Valores: \(x_{i1}=0, x_{i2}=1, x_{i3}=1\). El predictor lineal es: \(\beta_0 + \beta_2 + \beta_3\).

Mujer 2: sin antibióticos, sin factores de riesgo y cesárea planeada. Valores: \(x_{i1}=1, x_{i2}=0, x_{i3}=0\). El predictor lineal es: \(\beta_0 + \beta_1\).

El logaritmo de la razón de momios (log OR) de Mujer 1 vs Mujer 2 es la diferencia de los predictores lineales: \[ \text{log OR} = (\beta_0 + \beta_2 + \beta_3) - (\beta_0 + \beta_1) = -\beta_1 + \beta_2 + \beta_3 \]

# Extraemos coeficientes de M_inf
b_inf <- coef(M_inf)
V_inf <- vcov(M_inf)

# El vector de contrastes para L_c = -beta_1 + beta_2 + beta_3
# Coeficientes: (Intercept), cesarea_planeada, riesgo, antibioticos
c_c <- c(0, -1, 1, 1)

Lc_hat <- sum(c_c * b_inf)

var_Lc <- t(c_c) %*% V_inf %*% c_c
se_Lc <- sqrt(as.numeric(var_Lc))

ci_Lc_inf <- Lc_hat - z * se_Lc
ci_Lc_sup <- Lc_hat + z * se_Lc

cat("Estimación del log OR:", Lc_hat, "\n")
Estimación del log OR: -0.1525379

    exp(ci_Lc_inf), ",", exp(ci_Lc_sup), "]\n")
IC 95% para la razón de momios exp(log OR): [ 0.3087167 , 2.387521 ]

Este resultado indica que, a pesar de que la Mujer 1 presenta factores de riesgo y no planeó la cesárea, el hecho de administrarle antibióticos compensa estos riesgos. La razón de momios estimada en aproximadamente \(0.37\) (intervalo \([0.08, 1.83]\)) es menor a 1, indicando que sus momios de infección tienden a ser menores que los de la Mujer 2, aunque el intervalo cruza el \(1\), por lo que la diferencia no es estadísticamente significativa al 95%.
